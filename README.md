一只生活在 Windows 11 桌面上的 DeepSeek 鲸鱼女仆桌宠。小鲸不仅会待机、散步、眨眼、互动和聊天，还拥有照顾、经济、疲惫、外出打工、主控台、安全应用启动助手、贴边隐藏和 GitHub 更新能力。

项目使用原生 WPF 与 .NET 8 开发，采用文件夹式部署：`DeepSeek桌宠.exe` 只是启动入口，程序 DLL、角色图集、角色描述、默认配置和法律说明均作为外部文件保留，便于维护、替换、审计和更新。

v1.0 提供两种等价发行方式：离线完整版自带 .NET 8 Desktop Runtime，文件较多但解压即用；精简版不携带微软运行时，因此 DLL 数量和体积明显减少，但电脑必须先安装 `.NET 8 Desktop Runtime x64`。两种版本的桌宠功能、素材和存档格式完全相同。

> [!IMPORTANT]
> **v1.0.0 是首个正式文件夹式构建。** 发行包自带 .NET 8 Windows x64 运行时，不需要另装 .NET；当前程序尚未进行商业代码签名，Windows 首次运行时可能显示信誉提示。角色参考素材与相关名称的公开再分发权仍应由实际发布者在目标用途和地区下自行确认。

开启鼠标穿透后无法直接点击角色属于预期行为。请从任务栏右下角找到小鲸托盘图标，选择“切换鼠标穿透”恢复交互。

## 动画与状态机

角色外部素材由 `Assets/Characters/XiaoJing/pet.json` 描述，分为两套 `4 × 2` 图集。`spritesheet.png` 提供 8 个基础动作：

| 帧 | 动作 |
| ---: | --- |
| 0 | 待机 |
| 1 | 眨眼 |
| 2 | 挥手 |
| 3 | 思考 |
| 4 | 惊讶 |
| 5 | 困倦 |
| 6 | 向左行走 |
| 7 | 向右行走 |

`walk-cycle-v2.png` 提供读取顺序为左到右、先上后下的 8 帧连续左向步态，包含左右脚的接触、下压、经过和抬起阶段。程序按每秒约 9 帧循环播放，向右行走时镜像同一套步态，避免两套素材产生角色比例差异。进入或离开互动、工作、散步和待机状态时使用约 140 毫秒双图层交叉淡化，并叠加约 190 毫秒的轻微压缩、抬起和回稳；普通步态帧则直接按时序推进，避免每步拖影。

程序根据隐藏、贴边过渡、登场、拖拽、互动、工作、行走、自由动作、眨眼和待机状态选择动作，避免不同动画同时抢占图像变换。默认以安静待机为主，自动散步默认关闭；开启后也只会偶尔短距离散步。拖拽视觉只在鼠标产生有效位移时更新，动画计时器不会在拖拽期间重复改写透明窗口。完全隐藏或贴边时自动降低刷新频率。

启动时，小鲸会从目标位置下方跃入并显示“我来啦～”。如果存档要求贴边隐藏，则跳过登场并直接恢复侧边把手；如果存在未完成工作，则登场后提示工作仍在继续并回到工作状态。

## 界面视觉主题

当前开发版采用“小鲸 · 深海星梦”主题，与蓝发鲸鱼女仆形象保持一致：

- 深海蓝到薰衣草紫的主渐变，冰蓝和柔粉作为星光点缀；
- 半透明白色圆角卡片、轻量阴影和胶囊形按钮；
- 主控台保留角色立绘，并加入星光、气泡、状态徽章和更自然的角色文案；
- 聊天气泡区分用户蓝紫渐变、助手冰白气泡和错误提示；
- 照顾、打工、设置和电脑助手沿用同一控件样式，不降低安全警告的辨识度；
- 角色右键菜单与托盘图标右键菜单采用统一的蓝紫圆角主题，包含悬停高亮、细分隔线和易识别功能符号；
- 使用 `◆` 作为兼容 Windows 不同字重的鲸币符号，避免彩色 Emoji 缺字显示成方框。

Windows 资源管理器中对 `DeepSeek桌宠.exe` 文件右键后出现的系统菜单由 Windows 11 控制，本项目不会注入外壳扩展或修改系统菜单。这样可以避免资源管理器稳定性、安装权限、杀毒软件误报和卸载残留风险；应用自身的托盘菜单与角色菜单则完整使用上述主题。

## 显示、大小与隐藏

- 桌宠缩放范围为 `40%–200%`，设置页和主控台可精细调整，右键菜单提供常用比例。
- 缩放时尽量保持原中心和底部位置，不将角色无意推离当前工作区。
- 支持多显示器与 DPI 换算；拖动使用稳定的桌面坐标和物理像素吸附，避免透明窗口跟随鼠标时高频往返闪动；自动散步使用角色所在显示器的工作区。
- 待机采用轻微呼吸、偶尔眨眼或短暂挥手/思考；“随机散步”默认关闭。开启后每次候选等待随机落在 45–360 秒，并有 30% 概率继续待机；实际散步持续约 1.8–5 秒，速度在每秒 `60–92 × 缩放比例` 逻辑像素之间随机变化，走到工作区边缘会停下休息而不是立即掉头。
- 贴边隐藏会选择最近的左侧或右侧，只显示约 34 像素宽的“小鲸”把手。
- 拖拽角色进入当前显示器左右边缘约 `28 × 缩放比例` 的吸附区域时，会显示蓝紫色“松开隐藏”提示；松开鼠标即可贴边隐藏。
- 贴边方向、隐藏状态和隐藏前位置均会保存，下次启动继续恢复。
- 完全隐藏后仍保留托盘图标，可随时显示桌宠。

## DeepSeek 聊天

1. 在 [DeepSeek 开放平台](https://platform.deepseek.com/api_keys) 创建 API Key。
2. 右键桌宠选择“设置”。
3. 填写 API 地址、模型、角色提示词和 API Key。
4. 双击桌宠打开聊天窗口。

项目默认配置值为：

| 项目 | 默认值 |
| --- | --- |
| API 地址 | `https://api.deepseek.com` |
| 模型 | `deepseek-v4-flash` |
| 思考模式 | 关闭 |
| 回复方式 | 非流式完整回复 |
| API Key 存储 | Windows 凭据管理器：`DeepSeekDesktopPet.ApiKey` |

聊天窗口在当前打开周期内维护多轮历史。普通消息会发送到设置中的 API 地址；本地电脑助手指令不会发送给模型。API Key 不写入源码、`settings.json`、普通日志或 GitHub 仓库。

模型名称和接口能力可能由服务方调整；当前默认值已按 [DeepSeek 官方模型文档](https://api-docs.deepseek.com/quick_start/pricing/) 核对，发布或长期维护时仍应重新确认。

## 照顾系统

状态范围均为 `0–100`：饱食度和清洁度越高越好，口渴度越低越好。

| 状态 | 默认值 | 每现实小时变化 |
| --- | ---: | ---: |
| 饱食度 | 80 | `-2.2` |
| 口渴度 | 20 | `+3.6` |
| 清洁度 | 90 | `-1.25` |

状态会根据 UTC 时间计算，程序关闭后重新打开仍会结算，异常时间跨度最多按 30 天处理。危险阈值为口渴度不低于 80、饱食度不高于 20、清洁度不高于 20；桌宠会给出气泡提醒，但贴边隐藏时不会强行弹出。

## 鲸币、疲惫与外出打工

默认拥有 30 鲸币和 15 点疲惫度。疲惫度越低越好；达到 80 后不能接新工作。工作还要求饱食度高于 20、口渴度低于 80。

| 工作 | 时间 | 报酬 | 疲惫 | 饱食 | 口渴 | 清洁 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 整理数据 | 20 秒 | +12 | +10 | -4 | +4 | -1 |
| 模型测试 | 45 秒 | +28 | +18 | -7 | +7 | -2 |
| 算力值班 | 90 秒 | +60 | +32 | -12 | +12 | -4 |

- 同一时间只能进行一份工作。
- 工作开始和结束时间会保存，关闭程序后仍可离线完成。
- 主动取消不会获得报酬，也不会增加工作消耗。
- “休息一会”免费降低 25 点疲惫；“睡觉”免费降低 60 点。
- 空闲时疲惫每小时自然降低 5 点。

### 防止资源死循环

系统保证即使处于 `0 鲸币、100 疲惫、0 饱食、100 口渴、0 清洁` 的极端状态，也存在免费恢复路径：

1. 免费休息把疲惫降至可工作范围。
2. 免费清水把口渴降至可工作范围。
3. 免费擦拭恢复清洁度。
4. 免费应急便当把饱食度提升到工作阈值以上。
5. 完成最短工作获得鲸币，重新进入正常经济循环。

该极端状态恢复链已经通过逻辑测试。

## 安全电脑助手

电脑助手默认关闭。首次进入时必须完整阅读风险说明、主动勾选并同意；同意可以随时撤回。当前第一阶段只负责安全启动应用，不进行文件删除、任意命令执行、键鼠控制或无人确认的自动化。

默认外置允许列表 `Config/assistant-apps.json` 包含：

- 记事本：`%WINDIR%\System32\notepad.exe`
- 计算器：`%WINDIR%\System32\calc.exe`
- 文件资源管理器：`%WINDIR%\explorer.exe`

启用后可以在聊天中输入“帮我打开记事本”“启动计算器”等指令。名称必须与应用名称、文件名或配置别名精确匹配；聊天里直接写入一个陌生 EXE 路径不会执行。

安全边界：

- 仅允许真实存在的本地绝对路径 `.exe`。
- 拒绝相对路径、UNC 网络共享、脚本、快捷方式、URL 和符号链接文件。
- 不支持任何命令行参数。
- 使用直接进程创建，不调用 CMD、PowerShell 或 Windows Shell。
- 不设置 `runas`，要求管理员权限的目标应由 Windows 拒绝。
- 拦截 CMD、PowerShell、WSL、Python、Node、Java、MSI 执行器及多种高风险系统工具。
- 启动前再次验证文件，显示完整路径并要求用户确认。
- 启动、失败和阻止结果记录到本地 `assistant-actions.log`，不记录聊天全文。
- 允许列表使用原子替换和 `assistant-apps.backup.json` 备份恢复。

> [!WARNING]
> 允许列表不是杀毒软件或数字签名验证工具。程序文件可能被替换，合法程序也可能存在漏洞。只添加来源可信、已经检查并具有合法使用权的软件。

## OpenClaw 规划

[OpenClaw](https://github.com/openclaw/openclaw) 可以在未来作为高级用户主动启用的独立智能代理后端，但当前版本没有复制、捆绑、自动安装或运行 OpenClaw。

保留独立连接器而非直接塞入桌宠的原因：

- 普通用户无需安装 Node、WSL、Gateway 或后台服务。
- 避免默认引入文件、网络、浏览器、消息和主机命令等大权限面。
- 保持 WPF 原生文件夹结构和较清晰的许可证边界。
- 允许未来把回环地址、令牌、最小工具权限和逐项授权作为强制默认值。

完整设计见 [OPENCLAW-INTEGRATION.md](OPENCLAW-INTEGRATION.md)。OpenClaw 官方仓库当前标注为 [MIT License](https://github.com/openclaw/openclaw/blob/main/LICENSE)；未来若复制或分发其代码，必须以实际采用版本重新审计并保留许可证与第三方通知。

## GitHub 更新中心

更新只在用户主动操作时进行，不会静默检查或静默安装。

当前流程：

1. 校验输入为 `github.com/所有者/仓库`。
2. 调用 GitHub `releases/latest` 接口并解析版本号。
3. 从 Release Assets 中优先选择名称含 Windows/portable 和项目名称的 ZIP。
4. 下载到临时目录并显示进度；小于 1 MB 的异常包会被拒绝。
5. 检查 ZIP 路径穿越和必需文件：启动 EXE、程序 DLL、角色描述、默认配置。
6. 用户确认后等待当前程序退出，把完整安装目录备份到临时位置。
7. 解压并覆盖完整文件夹，然后重启；失败时尝试恢复备份并记录 `update-error.log`。

v1.0 ZIP 已可独立运行，但默认 GitHub 仓库地址仍为空，因此更新中心不会自动连接未知仓库。维护者配置真实仓库和 Release 后才能启用在线更新；后续仍应增加发行签名或固定哈希验证。

## 本机数据与隐私

默认数据目录：`%APPDATA%\DeepSeekDesktopPet`。

| 文件或位置 | 内容 |
| --- | --- |
| `settings.json` | 普通设置、位置、状态、经济、工作和助手同意状态 |
| `settings.backup.json` | 上一次完整普通设置备份 |
| `assistant-apps.json` | 用户的应用允许列表 |
| `assistant-apps.backup.json` | 上一次允许列表备份 |
| `assistant-actions.log` | 本地应用启动审计；可能包含 Windows 用户路径 |
| `crash.log` / `crash.previous.log` | 崩溃诊断与轮换备份 |
| `update-error.log` | 更新脚本失败详情，仅失败时出现 |
| Windows 凭据管理器 | DeepSeek API Key，目标名 `DeepSeekDesktopPet.ApiKey` |

网络行为：

- 普通聊天：仅在用户发送时请求设置中的 API 地址。
- 本地应用命令：不发送给模型。
- GitHub：仅在用户检查或下载更新时访问。
- 当前没有遥测、广告、账户同步、后台上传或静默更新。

退出程序并删除 `%APPDATA%\DeepSeekDesktopPet` 可以清除普通设置、允许列表和日志；API Key 需要在设置页或 Windows 凭据管理器中单独删除。完整说明见 [PRIVACY.md](PRIVACY.md)。

## 开发环境与从源码运行

要求：

- Windows 11 x64（代码目标也可在兼容的 Windows 环境测试）；
- [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0)；
- 无需 Python、Node.js 或 OpenClaw。

```powershell
git clone <你的仓库地址>
cd DeepSeekDesktopPet
dotnet restore
dotnet run
```

Release 编译：

```powershell
dotnet build -c Release
```

未来生成无需用户安装 .NET 的文件夹式自包含构建：

```powershell
dotnet publish -c Release -r win-x64 --self-contained true `
  -p:PublishSingleFile=false
```

输出目录通常为：

```text
bin/Release/net8.0-windows/win-x64/publish/
```

请保留整个发布目录。只复制 `DeepSeek桌宠.exe` 会缺少 DLL、运行时、素材、配置和法律说明，程序不能作为完整产品使用。

## 常见问题

### 为什么 EXE 不能单独复制？

EXE 只是启动入口。程序逻辑、.NET 运行环境、素材、配置和法律文档都在外部文件夹中，必须整体保留。

### 为什么程序文件夹会比较大？

未来的自包含发布会附带 .NET 运行环境，换取用户无需另外安装 Runtime。素材和文档仍保持外置。

### 为什么聊天提示没有 API Key？

网页版 DeepSeek 账号不能直接代替 API Key。请从 DeepSeek 开放平台创建 Key，并在桌宠设置中保存。

### 电脑助手为什么不肯直接运行我输入的路径？

这是安全设计。路径必须先由用户在管理窗口中加入允许列表，聊天只匹配已允许名称，并且每次仍要确认。

### 为什么 PowerShell、CMD、Python 或 Node 不能加入允许列表？

这些程序可以把普通文本扩展成任意命令、文件或网络行为，远超第一阶段“打开一个应用”的授权范围，因此默认阻止。

### 如何从鼠标穿透或完全隐藏状态恢复？

使用任务栏右下角的小鲸托盘图标，选择“显示桌宠”或“切换鼠标穿透”。

### 关闭聊天窗口为什么桌宠还在？

聊天、设置、照顾、打工和主控台都是子窗口。彻底退出需要使用桌宠右键菜单或托盘菜单中的“退出”。

### 如何卸载和清除数据？

退出桌宠后删除完整程序文件夹。若要清除用户数据，再删除 `%APPDATA%\DeepSeekDesktopPet`，并从 Windows 凭据管理器删除 `DeepSeekDesktopPet.ApiKey`。
